
# Real-Time UPI Fraud Detection System

## Project Description
An ML-based application for detecting potentially
fraudulent UPI-like transactions.

## Technology Stack
- React.js
- Python
- FastAPI
- Scikit-learn
- PostgreSQL
- Pandas
- NumPy

## Project Modules
1. Transaction Processing
2. Fraud Prediction
3. Risk Analysis
4. Fraud Alerts
5. Analytics Dashboard
